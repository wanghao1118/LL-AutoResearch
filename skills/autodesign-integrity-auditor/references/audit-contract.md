# Integrity Audit Contract

## Required evidence

| Requirement | Authoritative artifact | Pass condition |
| --- | --- | --- |
| Input fidelity | input brief and original request | claims and explicit locks preserved |
| Route validity | method route and R0 | selected route justified and required R0 observed |
| Evidence coverage | evidence plan | every claim and test axis has a falsifier |
| Implementation fidelity | generated project and notes | accepted experiments and protocol implemented |
| Execution completion | execution record and logs | current smoke, experiment, aggregate exit zero in order |
| Result completeness | raw results and summary | scheduled and observed cells and metrics match |
| Numeric integrity | raw results, tables, figures | recomputed values match all displays |
| Route closure | result route, tuning record, next round, latest execution and diagnosis | no required action remains unexecuted or unrediagnosed |
| Claim scope | diagnosis and report text | conclusions do not exceed observed evidence |

## Verdict

Use PASS only when every requirement has direct evidence and no unresolved blocker. Use FAIL for a concrete contradiction or missing required evidence. Do not replace the verdict with a score.
